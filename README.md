# Class Activity Notebooks (ML and AI)

This repository is a collection of coursework notebooks covering core ML and AI topics.

## Notebook Topics

- Clustering: `Mall_Customers_Clustering.ipynb`, `Wholesale_Customers_Clustering.ipynb`
- Computer Vision/Neural Nets: `CNN_w_MNIST.ipynb`, `MNIST_Neural_Network.ipynb`, `MNIST_Neural_Network_6_Obs.ipynb`
- Reinforcement Learning: `Reinforcement_Learning.ipynb`
- Intro datasets: `Iris.ipynb`, `Penguins.ipynb`, `Housing.ipynb`

## Purpose

- Demonstrates practical hands-on exercises across multiple machine learning domains.
- Serves as a consolidated academic practice repository.
